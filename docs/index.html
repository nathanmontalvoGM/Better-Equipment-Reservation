Better Checkout

Know what's available before you book.

Better Checkout is a free add-on for MTSU's Connect2 equipment checkout. Pick your dates, see what's available right on the equipment list, save the gear you always take, and book it in a few clicks.

Install it See how it works

Install it

About two minutes, once per computer. Use a laptop or desktop: add-ons like this don't work on most phones.

Safari isn't supported. Use Chrome, Edge, or Firefox for Connect2 and follow the steps for that browser.

  1. Add Tampermonkey

    Tampermonkey is a free, widely used extension that runs small add-ons like Better Checkout.

    Get Tampermonkey for Chrome Get Tampermonkey for Edge Get Tampermonkey for Firefox

    On that page, click Add to ChromeGetAdd to Firefox, then confirm.

  2. Let Tampermonkey run add-ons

    Chrome asks you to switch this on once. Right-click the Tampermonkey icon in your toolbar (it may be inside the puzzle-piece menu), choose Manage extension, and turn on Allow User Scripts.

    Skipping this is the most common reason nothing shows up.

    Edge asks you to switch this on once. Copy this address into a new tab, then turn on Developer mode.

    edge://extensions

    Skipping this is the most common reason nothing shows up.

  3. Install Better Checkout

    Tampermonkey opens a page about Better Checkout. Click Install on it.

    Install Better Checkout

    If you just see a page of code instead, Tampermonkey isn't installed or switched on yet. Go back a step.

  4. Open Connect2

    Sign in to Connect2, then go to Book by Category → Media Arts Equipment. Better Checkout appears in the bottom-right corner, with a bar above the equipment list:

    Updates install themselves.

How to use it

Everything Better Checkout adds to Connect2 has its slate logo, so you can always tell what's Connect2 and what's the add-on.

  • Pick your dates

    Press Pick your dates above the equipment list and set when you'll pick up and return the gear.

  • See what's available

    Every item says whether it's available for your dates. Turn on Only show gear that's available to hide the rest.

  • Save your usual gear

    In the panel, choose New preset, then press + Preset under each item you take. Add backups for anything that might be taken.

  • Book it

    Press Book these dates. Better Checkout adds your gear and fills in the times, then stops at Terms & Conditions so you finish the booking yourself.

Not working?

  1. Make sure you're on Book by Category → Media Arts Equipment, not Connect2's home page, and reload it.
  2. Open Tampermonkey's dashboard (click its icon) and check that Better Checkout is listed and switched on.
  3. In Chrome, check that Allow User Scripts is still on (step 2).In Edge, check that Developer mode is still on (step 2).In Firefox, check that Tampermonkey is enabled under Add-ons and themes.
  4. Still stuck, or something looks wrong? In the panel, open Share and Help, press Copy problem report, and send it to whoever shared Better Checkout with you. It never includes your name or login.

What it never does

  • See your passwordIt works inside the Connect2 tab you're already signed in to.
  • Book without youIt stops at Terms & Conditions. You accept, verify, and complete every booking.
  • Send your data anywhereYour presets and dates stay in your browser. It only talks to Connect2.
